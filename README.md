# DIO_Bootcamp_Santander_Excel_Desafio_Projeto_03
Desafio de Projeto 03 - Bootcamp DIO Santander Excel com IA e Claude

Esse material é referente ao Desafio de Projeto “Criando uma Dashboard de Vendas do XBOX no Excel” para o curso DIO. Bootcamp Santander Excel com IA, e consiste nos seguintes arquivos:

- DIO_Bootcamp_Santander_Excel_IA_Desafio_de_Projeto_03.xlsx (arquivo Excel em .xlsx)
- DIO_Bootcamp_Santander_Excel_IA_Desafio_de_Projeto_03.pdf (dashboards em .pdf)
  
O desafio consiste em criar uma dashboard interativa com a base de dados de vendas de produtos XBOX, fornecida pela instituição para o projeto do curso. E foi utilizada basicamente ferramentas de gráficos dinâmicos e segmentação de dados sobre as colunas de dados da planilha. 

Foi um desafio muito interessante para o uso exclusivo do Excel para a construção de dashboards interativos.
